# SQLite-слой (заготовка)

Здесь будет персистентное хранилище бота.

Планируемая структура:

- `connection.py` — единая точка соединения (aiosqlite)
- `history.py` — история диалогов (сейчас в памяти в `llm_client.py`)
- `facts.py` — факты о пользователях
- `settings.py` — настройки серверов/пользователей

Пока модуль пуст. История диалогов остаётся в памяти
и обращается к ней только через `_build_messages` / `_save_response` / `clear_history`,
чтобы потом подменить хранилище без правок вызовов.
